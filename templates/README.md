# UI layout templates

These files are a design sandbox for describing intended game layouts with faux HTML/CSS.

They are not loaded by the Love2D runtime. Use them to iterate on regions, grid spans, colours, borders, and rough proportions. The Lua UI can then be updated to match the agreed templates.
